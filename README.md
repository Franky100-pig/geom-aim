# GEOM AIM

本地单机伪 3D 第一人称射击训练器。射线渲染（raycasting），Python + pygame，无外部素材（音效由 numpy 合成）。包含靶场练习、3v3 回合对抗、5v5 积分赛三种模式。

## 运行

各系统双击 / 运行对应启动器，脚本会自动检查并安装依赖后再启动：

| 系统 | 启动器 |
| --- | --- |
| macOS | 双击 `启动游戏.command` |
| Windows | 双击 `start.bat` |
| Linux | 终端执行 `./start.sh`（首次需 `chmod +x start.sh`） |

命令行（任意系统）：

```bash
pip install -r requirements.txt
python3 main.py
```

启动后进入标题界面，按 `1` / `2` / `3` 选择模式。

## 模式

| 键 | 模式 | 说明 |
| --- | --- | --- |
| `1` | 练习 | 5 种靶场训练（见下） |
| `2` | 对战 | 3v3 回合制对抗，含经济与买枪 |
| `3` | 积分赛 | 5v5 连续重生 TDM，先到 25 杀获胜 |

对战与积分赛地图每局随机生成 **180° 旋转对称** 的掩体（半高箱 / 高箱）；练习模式为固定柱。

## 对战模式（3v3 回合制）

你 + 2 名队友 AI 对抗 3 名敌人 AI，双方均会交火、买枪、使用烟雾弹。

- **赛制**：best of 7，先到 4 回合胜。
- **流程**：买枪(prep, 10s, 可移动) → 交火(live, 90s) → 结算(2.5s) → 下一回合。
- **死亡**：一回合一条命，阵亡后第一视角观战存活队友至回合结束。
- **胜负**：一方 3 人全灭则另一方得分；时间到则存活多者胜，相同判平。
- **经济**：起始 $800；胜 +3250 / 败 +1400；连败补偿递增；击杀按枪械分档奖励；上限 $16000。AI 按资金买枪。
- **武器**：手枪 / 冲锋枪 / 步枪 / 连狙 / 狙击，共 5 把（无护甲、无投掷物，烟雾弹单独购买）。爆头乘伤害倍率。
- **难度**：4 档 + 逐回合自适应（依近 3 回合 KD 与胜率 ±20% 微调）。

| 档 | 反应延迟 | 瞄准误差 | 横移 |
| --- | --- | --- | --- |
| 简单 | 0.55s | 6.5° | 少 |
| 普通 | 0.38s | 4.0° | 中 |
| 困难 | 0.25s | 2.2° | 多 |
| 专家 | 0.16s | 1.2° | 多 |

- **AI 判定**：敌我共用同一套命中几何，瞄准点带高斯误差，超出人形轮廓即打偏；走位与掩体可真实降低被命中率。
- **战绩**：命中率 / KD / 爆头率，回合与整场结束均展示。

## 积分赛（5v5 连续重生 TDM）

你 + 4 名队友 AI 对抗 5 名敌人 AI，无经济、可随时换枪。

- **胜负**：先累计 **25 击杀** 的队伍获胜。
- **重生**：阵亡后约 **1.5s** 重生，重生后 **3s** 无敌。
- **换枪**：`1`–`5` 随时免费换枪，无需购买。
- **地图**：3×3 拼接（房间 25×17），随机对称掩体，无烟雾弹。
- 命中 / 难度 / 战绩逻辑同对战模式。

## 练习模式（5 种）

| 模式 | 训练 |
| --- | --- |
| AIM BOTZ | 甩枪点靶，5–10 靶同时，清掉补位，进阶混入横移靶 |
| REFLEX | 闪现反应，单靶限时 0.7s→0.32s 递减并缩小 |
| TRACKING | 跟枪压枪，黏住高速乱跑的靶，断 0.85s 连击清零 |
| PEEK | 掩体探头，靶从柱后滑出才可击中 |
| SNIPER | 远距狙击，右键开/关镜 4x，左键单发需上栓 |

## 枪感与调参

AK 手感：600 RPM，前几发近直上，后向右摆再回摆（`player.py` 的 `SPRAY_YAW_PATTERN`）。连发越久扩散越大，移动附加扩散，站定最准。爆头区在身高 78%–94%（250 分），躯干 100 分，连击第二起每级 +5%（封顶 2.5x）。

主要参数在 `config.py`，改完重开生效：

- `MOUSE_SENS`：灵敏度（`[` `]` 游戏内可调）
- `H_FOV_DEG`：水平视场角，默认 90（`-` `=` 可调）
- `RECOIL_PX` / `RECOIL_RECOVER_PX`：后坐力上抬与回正
- `SPRAY_PER_SHOT` / `SPRAY_MAX`：连发扩散
- `RENDER_COL_STEP`：射线精度，默认 2（卡则改 3/4，求锐利试 1）
- `AI_DIFF_*` / `ECON_*` / `MATCH_*` / `SCORE_*`：对战与积分赛数值
- 游戏内 `L` 热重载配色

## 掩体系统

对战与积分赛地图每局随机生成，满足：180° 旋转对称、全图连通、出生点四周留空。

- **半高箱**（高 0.70）：高于站立眼高，站立不可穿透；蹲下（头顶 0.65 < 0.70）完全藏住，站立露头可见；跳起平射可越过。
- **高箱**（高 1.0）：等同满高墙，绝对遮挡。

满高外墙与房间墙始终为绝对遮挡，跳跃无法越过。

## 场地规模

地图由 `ARENA_TILES_X × ARENA_TILES_Y` 个房间拼接，房间开门洞连通，外圈封外墙。改 `config.py` 顶部 `ARENA_*`：

- `ARENA_TILES_X` / `ARENA_TILES_Y`：房间数（默认 4×3 = 12）
- `ARENA_ROOM_W` / `ARENA_ROOM_H`：单房间尺寸

默认约 109×57 格。对战 / 积分赛另有各自的 `MATCH_*` / `SCORE_*` 尺寸参数。

## 狙击配置

- `ADS_ZOOM`：开镜倍率，默认 4
- `BOLT_TIME`：栓动延迟，默认 0.9s（设 0 变连点）
- `SNIPER_SENS_MUL`：开镜灵敏度乘子，默认 0.28
- `SNIPER_DIST_MIN` / `SNIPER_DIST_MAX`：远距靶刷新距离

### 渲染数学约定

改 `engine.py` 前先看文件头注释。核心三条：

- 射线 `ray = dir + plane_unit * s`，`dir` 分量恒为 1，DDA 参数即垂直距离，无鱼眼。
- 屏幕纵坐标 `y = horizon + (H * vscale / d) * (EYE_HEIGHT - h)`，`vscale = W / (2 * L * H)` 保证像素密度一致。
- 上下看靠平移地平线：`horizon = H/2 + pitch_px`；准星在深度 d 处的世界高度为 `EYE_HEIGHT + pitch_px * d / (H * vscale)`，命中判定用之。

## 注意事项（易错点）

- **pygame 2 窗口事件扁平**：用 `pygame.WINDOWFOCUSLOST` / `pygame.WINDOWMINIMIZED`，无 `pygame.WINDOWEVENT` 子属性写法，否则切窗口瞬间崩。
- **`Renderer` 建 Surface 前需检查 `pygame.display.get_init()`**：无头环境 `Surface.convert()` 会抛异常。

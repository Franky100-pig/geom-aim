# GEOM AIM

一个本地单机的**伪 3D 第一人称练枪房 + 3v3 对抗**。CS2 味的靶场训练，外加一个
你 + 2 队友 AI vs 3 敌人 AI 的回合制对抗模式。射线渲染（raycasting），
Python + pygame，零素材依赖（音效是 numpy 现场合成的）。

## 怎么跑

macOS：**双击 `启动游戏.command`**

或者命令行：

```bash
python3 main.py
```

需要先装依赖（装一次就行）：

```bash
pip install -r requirements.txt
```

启动后先到**标题界面**，用 `1` / `2`（或回车）选择：

* `1` **对战** —— 进 3v3 回合制对抗
* `2` **练习** —— 进原来的五个靶场模式

## 对战模式（3v3 回合制）

你（玩家）+ 2 名队友 AI，对抗 3 名敌人 AI，**全员都会打、会互相交火、会买枪**。

* **赛制**：best of 7，先拿到 4 个回合胜场赢。
* **回合流程**：`买枪(prep, 10s, 可移动) → 交火(live, 90s) → 结算(2.5s) → 下一回合`。
* **一条命一回合**：死了就**第一视角自动观战还活着的队友**，直到回合结束。
* **回合胜负**：一方 3 人全灭 → 另一方拿分；时间到则存活人数多者胜，人数相同判平局（双方都不得分）。
* **经济**：起始 \$800；胜 +3250 / 败 +1400；连败补偿递增 1400→3400；击杀按枪械分档奖励；上限 \$16000。队友 AI 也会按钱买枪。
* **武器 5 把**（无护甲、无投掷物）：手枪 / 冲锋枪 / 步枪(AK 手感) / 连狙 / 狙击(栓动 4x 镜)。爆头直接乘伤害倍率。
* **难度四档** + 逐回合自适应（依据你近 3 回合的 KD 和回合胜率，±20% 带宽微调）：

  | 档 | 反应延迟 | 瞄准误差 | 点射稳度 | 横移 |
  | --- | --- | --- | --- | --- |
  | 简单 | 0.55s | 6.5° | 弱 | 少 |
  | 普通 | 0.38s | 4.0° | 中 | 中 |
  | 困难 | 0.25s | 2.2° | 强 | 多 |
  | 专家 | 0.16s | 1.2° | 很强 | 多 |

* **AI 不作弊**：敌我共用同一套命中几何——瞄准点带高斯误差，误差超过你的人形轮廓就算打偏。你移动、贴掩体是真的能降低被命中率。
* **战绩**：命中率 / KD / 爆头率，回合结束与整场结束都展示。

> 难度和经济的数值只能靠手感调，全部集中在 `config.py`（`AI_DIFF_*`、`ECON_*`、`MATCH_*`），
> 游戏内按 `L` 热重载配色、`[` `]` 调灵敏度，**改完立刻生效不用重启**。

## 五个练习模式

| 模式 | 练什么 |
| --- | --- |
| **AIM BOTZ** | 甩枪点靶。靶场里同时 5–10 个靶，清掉就补位，难度上来后会混进横移靶 |
| **REFLEX** | 闪现反应。一次只出一个，限时 0.7s → 0.32s 递减，还会越缩越小 |
| **TRACKING** | 跟枪压枪。一个高速乱跑的靶，黏住它别断，断 0.85 秒连击清零 |
| **PEEK** | 掩体探头。靶子从柱子/掩体后滑出来才打得着，缩回去时打不到 |
| **SNIPER** | 远距狙击。右键轻点开/关镜放大 4x + 灵敏度降低，左键单发、打完要上栓（BOLT_TIME），远距小靶不开镜几乎打不中 |

## 枪感

AK 那套：600 RPM，前几发几乎直上，之后往右摆再往左回（`player.py` 里的
`SPRAY_YAW_PATTERN`）。连发越久扩散越大，移动时额外加扩散，站定最准。
爆头区在身高 78%–94% 的位置，250 分；躯干 100 分。连击从第二发起每级 +5%，封顶 2.5x。

## 调手感

全在 `config.py` 里，改完重开即可：

* `MOUSE_SENS` — 鼠标灵敏度（也能在游戏里按 `[` `]` 调）
* `H_FOV_DEG` — 水平视场角，默认 90（游戏里 `-` `=` 调）
* `RECOIL_PX` / `RECOIL_RECOVER_PX` — 后坐力上抬幅度和回正速度
* `SPRAY_PER_SHOT` / `SPRAY_MAX` — 连发扩散
* `RENDER_COL_STEP` — 射线精度，默认 `2`。拼接式大地图下整帧约 2.7 ms（CPU 允许约 365 fps），
  余量仍然很大。卡的话改 `3` 或 `4`；想更锐利可以试 `1`（整帧约 4.7 ms）

## 场地规模（拼接式竞技场）

地图由 `ARENA_TILES_X × ARENA_TILES_Y` 个房间直接拼成，房间之间开门洞连通，
外圈封一圈外墙。改 `config.py` 顶部那四个 `ARENA_*` 就能调场地大小：

* `ARENA_TILES_X` / `ARENA_TILES_Y` — 横向 / 纵向房间数（默认 4×3 = 12 个房间）
* `ARENA_ROOM_W` / `ARENA_ROOM_H` — 每个房间内部尺寸（格）

默认 4×3 映射出来约 109×57 格，狙击能拉出长视线、走位也更自由。
想更"无限"就调大 `ARENA_TILES_*`，想更顺手就调小。

## 狙击模式配置

* `ADS_ZOOM` — 开镜放大倍率（FOV 自动收窄），默认 4
* `BOLT_TIME` — 栓动上栓延迟，默认 0.9s（设 0 变连点）
* `SNIPER_SENS_MUL` — 开镜灵敏度乘子，默认 0.28
* `SNIPER_DIST_MIN` / `SNIPER_DIST_MAX` — 远距靶的刷新距离区间（受场地大小限制）

## 性能

`python3 tests/bench.py`（1280x720，CPU 侧，dummy 驱动）：

```
天花板/地板渐变   0.068 ms
地板网格          0.158 ms
墙体光栅化        2.343 ms   ← 主要开销，随 RENDER_COL_STEP 线性变化
HUD + 准星 + 枪   0.133 ms
整帧 update+draw  2.736 ms   → CPU 允许约 365 fps（拼接式大地图下）
```

对比 60 fps 的 16.7 ms 预算，余量巨大。真机还有 vsync 和合成开销，
但即使翻几倍也稳。

### 渲染的数学约定

改 `engine.py` 前先看文件头的注释。核心三条：

* 射线写成 `ray = dir + plane_unit * s`，`dir` 分量恒为 1，所以 DDA 出来的
  参数天然就是**垂直距离**，不会有鱼眼。
* 屏幕纵坐标 `y = horizon + (H * vscale / d) * (EYE_HEIGHT - h)`，
  其中 `vscale = W / (2 * L * H)` 保证横竖像素密度一致（不变形）。
* 上下看（pitch）靠平移地平线实现：`horizon = H/2 + pitch_px`。
  这也意味着准星在深度 d 处指向的世界高度是
  `EYE_HEIGHT + pitch_px * d / (H * vscale)`，命中判定用的就是它。

## 两个容易写错的地方

改代码时踩过，留个记号：

* **pygame 2 的窗口事件是扁平的** —— 用 `pygame.WINDOWFOCUSLOST`、
  `pygame.WINDOWMINIMIZED`，**不存在** `pygame.WINDOWEVENT` 那种带 `.event`
  子属性的写法（那是 SDL 原生结构）。写错的话只在切窗口的瞬间崩，
  平时测不出来。
* **`Renderer` 建 Surface 前要先看 `pygame.display.get_init()`** ——
  无头环境下 `Surface.convert()` 会抛异常，跑不了自动化测试。
